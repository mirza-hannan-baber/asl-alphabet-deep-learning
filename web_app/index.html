Deep Learning-Based American Sign Language (ASL) Recognition: Comparing Custom Convolutional Networks with Transfer Learning

Course: Deep Learning (CS-401) • Semester Project Report • Student: Mirza
📄 Download Word Report (.docx) 📊 Download Slides (.pptx)

1. Abstract

American Sign Language (ASL) serves as the primary communication medium for millions of hearing-impaired individuals worldwide. Automated sign language translation using computer vision enables inclusive human-computer interaction. This paper presents the design, implementation, and empirical evaluation of two distinct deep learning paradigms for classifying 29 ASL hand gestures from 87,000 images: a Custom Deep Convolutional Neural Network (CNN) constructed from scratch with hierarchical feature extraction, and a MobileNetV2 transfer learning model. The custom CNN achieves 98.4% test accuracy with 1.45M parameters, while MobileNetV2 achieves 99.6% accuracy. Model weights were extracted, serialized, and deployed in a production-ready web application on Vercel.

2. Problem Statement & Objectives

Manual gesture recognition in video streams suffers from variations in skin tone, lighting conditions, hand morphology, and minor intra-class pose deviations (e.g., distinguishing letters 'M', 'N', and 'T'). Our primary objectives were:

  • To develop an end-to-end computer vision pipeline capable of classifying static hand gesture images into 29 discrete classes.
  • To architect a lightweight, multi-block Custom CNN from scratch without relying on pre-trained weights.
  • To extract, verify, and serialize raw weights (.weights.h5) for automated testing crawlers.
  • To deploy an interactive web interface on Vercel enabling webcam-based real-time inference.

3. Custom Deep CNN Architecture & Mathematical Formulation

The custom architecture utilizes 4 sequential convolutional stages with progressive channel depth $(32 \to 64 \to 128 \to 256)$. Each convolution block performs the operation:

$$y = \text{ReLU}\left(\text{BatchNorm}\left(W * x + b\right)\right)$$

Spatial downsampling is achieved via non-overlapping $2 \times 2$ Max Pooling:

$$p_{i,j} = \max_{0 \leq m, n < 2} x_{2i+m, 2j+n}$$

To eliminate parameter explosion associated with standard Flatten layers, Global Average Pooling computes spatial averages:

$$\text{GAP}(x_c) = \frac{1}{H \times W} \sum_{i=1}^{H} \sum_{j=1}^{W} x_c(i,j)$$

Finally, class probabilities are produced via the multi-class Softmax function:

$$\sigma(z)_i = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}, \quad K = 29$$

4. Hyperparameters & Training Regularization

The model was compiled with the Adam optimizer ($\beta_1 = 0.9, \beta_2 = 0.999$, initial $\text{lr} = 0.001$). Categorical cross-entropy with label smoothing factor $\alpha = 0.05$ was employed to prevent overconfidence:

$$L_{\text{LS}} = -(1 - \alpha) \log(p_y) - \frac{\alpha}{K} \sum_{k=1}^{K} \log(p_k)$$

An adaptive learning rate scheduler (ReduceLROnPlateau) decreased the learning rate by a factor of $0.5$ whenever validation loss stagnated for 2 consecutive epochs.

5. Weights Extraction & Verification

Weights were extracted through the Keras serialization API into HDF5 binary format (custom_asl_weights.weights.h5). An independent verification unit reconstructed a fresh model instance without weights, loaded the serialized tensor checkpoint via model.load_weights(), and verified that maximum prediction divergence remained strictly zero ($\Delta = 0.000000 \times 10^0$).
